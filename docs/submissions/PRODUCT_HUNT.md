### Description:
```text
Linux2Win is a modern open-source tool that lets Windows 10 & 11 users easily view and copy files from Linux disks (Ext2/Ext3/Ext4) directly through native Windows File Explorer.

✨ Highlights:
• Auto-Detect & Hotplug: Automatically detects connected and newly plugged Linux USB drives.
• Native Explorer Integration: Files appear directly in C:\LinuxDisks using Windows Projected File System (ProjFS) — no 3rd-party kernel drivers needed!
• 100% Read-Only Safety: Physical disk handles are locked in read-only mode to prevent any accidental filesystem corruption.
• Smart Partition Filter: Automatically excludes boot, EFI, and swap partitions to only mount real data.
• Memory-Resident Daemon: Optional System Tray monitor with startup consent and notification alerts.
• Free & Open Source under MIT.
```

Hi Product Hunt! 👋

I created Linux2Win because sharing data from dual-boot Linux drives or Linux USB sticks on Windows has always required either complex virtualization, third-party kernel drivers, or clunky extractors.

Linux2Win uses Windows 10/11 native Projected File System (ProjFS) and a lightweight C++20 ext4 engine to project your Linux folders directly into File Explorer with zero kernel driver installations and strict read-only safety guarantees.
