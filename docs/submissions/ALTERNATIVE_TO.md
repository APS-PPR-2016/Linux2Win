- **Application Name**: Linux2Win

- **License**: Open Source / MIT
- **Platforms**: Windows (Windows 10, Windows 11)
- **Tags**: Ext4, Ext3, Ext2, File Explorer, File System, Linux, Windows, Storage, USB, Disk Management
- **Description**:
  > Linux2Win is a modern open-source tool that lets Windows users view and copy files from Linux disks (Ext2/Ext3/Ext4) directly through native Windows File Explorer using Windows Projected File System (ProjFS). It includes real-time USB hotplug detection, read-only safety guarantees, and automatic exclusion of boot/swap partitions.
